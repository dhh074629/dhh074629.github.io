怎么加一个新软件

一条命令：复制设计模板、建仓库、开 Pages、在首页登记一张卡片。

cd outputs/lab-hub
pwsh deploy/new-software.ps1 -Name myapp-site -Title "我的软件" -Description "一句话说明它解决什么" -Publish

脚本会在 outputs/ 下生成 myapp-site/，用统一的设计系统搭好骨架， 创建公开仓库并开启 Pages，最后把条目写进 projects.js，这一页刷新就能看到新卡片。 去掉 -Publish 则只在本地生成，先写好内容再上线。

为什么这样摆

每个软件一个仓库

独立部署、独立历史。一个项目改出问题，不会连累其他站点；不想要了直接归档，不影响别人。

根路径留给首页

仓库名正好是 <用户名>.github.io 时，它的站点独占域名根路径，其他仓库自动落到 /<仓库名>/。

设计系统只有一份

配色、字体、卡片样式都在 styles.css 里。新软件复制它，改一处全站生效，不会越做越乱。

速度不够再加一层

GitHub Pages 在国内偶发慢。真要让别人常看时，套一层 Cloudflare Pages 或国内 OSS+CDN 即可，源头仍是这个仓库。
